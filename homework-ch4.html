PVT 实验数据综合题：Bt、日产气、地下体积、Co

综合应用 ★ 答案：Bt=1.603；qg=6700 m³/d；地下油 2.882 m³ + 气 2.752 m³；Co=1.92×10⁻³ MPa⁻¹
题目 某油藏原始油层压力 p=23.56MPa。该油井样品实验室 PVT 分析结果如下表（pb=20.77MPa 为泡点压力）：
p (MPa)Bo (m³/m³)Rs (m³/m³)Bg (m³/m³)
27.211.517167.5—
23.811.527167.5—
23.131.530167.5—
22.451.532167.5—
21.771.534167.5—
21.091.537167.5—
20.77 (pb)1.538167.50.004858
18.371.484145.80.005464
16.331.441130.30.006115
14.291.4011150.007023

读表要点：泡点以上 Rs 恒为 167.5（气全部溶完）、Bg 无意义（无自由气）；泡点以下降压才脱气。

（1）p=18.37MPa 时总体积系数；（2）地层压力 21.77MPa 时，油井日产 40m³ 地面原油，问地面日产气多少？（3）地层压力 16.33MPa 时，日产天然气 450m³（标准），地面原油 2m³，问这些原油、天然气在地层中各占多少体积？（4）21.77～22.45MPa 之间，原油的等温压缩系数为多少？
思路 · 方法标注 四个小问各考一个定义式，关键是先判断每问所处的压力区间（泡点以上还是以下）：
（1）泡点以下＝油气两相，总体积系数（两相体积系数）Bt = Bo + (Rsb − Rs)·Bg：1 m³ 地面油 + 它在地下还脱出的 (Rsb−Rs) m³ 标准气的地下体积；
（2）21.77MPa > pb：欠饱和，地层内无自由气，产出气全部是溶解气，qg = qo·Rs；
（3）地下体积 = 地面体积 × 体积系数：油 Vo=Vosc·Bo，气 Vg=Vgsc·Bg；
（4）等温压缩系数定义 Co = −(1/Bo)·(dBo/dp)，两压力点间用差分。
1
（1）Bt(18.37MPa)：查表 Bo=1.484，Rs=145.8，Bg=0.005464；Rsb=167.5（泡点值）。
Bt = 1.484 + (167.5−145.8)×0.005464 = 1.484 + 21.7×0.005464 = 1.484 + 0.1186 = 1.603 m³/m³。
含义：18.37MPa 下每 1 m³ 地面油，在地层中连同已脱出的气共占 1.603 m³。
2
（2）地面日产气：21.77MPa 高于泡点 20.77MPa，天然气 100% 溶于油中（Rs=Rsb=167.5），地层内没有自由气可单独采出。
qg = 40×167.5 = 6700 m³/d（标准条件）。
3
（3）16.33MPa 下的地下体积：查表 Bo=1.441，Bg=0.006115。
油：Vo = 2×1.441 = 2.882 m³；气：Vg = 450×0.006115 = 2.752 m³（合计 5.634 m³/d，即该井地下日采出体积）。
注意 450 m³ 是标准体积，必须乘 Bg 换算到地层条件（高压下气体被压缩，Bg≈1/165）。
4
（4）Co：21.77→22.45MPa，Bo 由 1.534 降到 1.532。
dBo/dp = (1.534−1.532)/(21.77−22.45) = 0.002/(−0.68) = −2.941×10⁻³ MPa⁻¹；
Co = −(−2.941×10⁻³)/1.533 = 1.92×10⁻³ MPa⁻¹（≈1.32×10⁻⁵ psi⁻¹，量级正常）。
图：按本题数据绘制——泡点以上 Bo 随降压微增（弹性膨胀）、Rs 平台；泡点以下脱气，Bo 与 Rs 同步陡降（本题第(4)问的 Co 只在泡点以上用）
答案 （1）Bt(18.37MPa) = 1.603 m³/m³；
（2）地面日产气 = 40×167.5 = 6700 m³/d；
（3）地下体积：原油 2.882 m³，天然气 2.752 m³（合计 5.63 m³/d）；
（4）Co = 1.92×10⁻³ MPa⁻¹（21.77～22.45MPa 区间）。
标注要点
  1. 先看压力在泡点上方还是下方——本题四个小问的解法完全由这一判断决定：泡点以上无自由气（Rs=Rsb、Bg 无值），泡点以下才有两相计算。这是 PVT 综合题的第一思维。
  2. Bt 是“油+它脱出的气”合在一起的地下体积：只对泡点以下有意义（泡点处 Bt=Bo，最大值 Bob=1.538，可代入验证：p=18.37 时 Bt=1.603>1.538 ✓ 随压力降低继续增大）。
  3. Co 只在泡点以上定义才有意义：泡点以下降压时 Bo 的变化受“脱气”控制，不再是纯弹性压缩；所以题目特意选 21.77～22.45MPa（泡点以上）区间。
  4. 易错：（2）问不要再乘 Bg——6700 m³ 是“地面/标准”日产气量；（3）问 450 m³ 是标准体积，忘乘 Bg 直接答 450 是最常见的丢分点。

地层水的等温压缩系数（图版法）

图版法 答案：Cw ≈ 4.4×10⁻⁴ MPa⁻¹（≈3.0×10⁻⁶ psi⁻¹）
题目 计算油藏压力为 14.0MPa、油藏温度为 80℃、含盐量为 40000mg/L 的地层水的压缩系数。
思路 · 方法标注 教材方法＝纯水压缩系数图版 + 矿化度校正，两步：
① 查纯水等温压缩系数图版（Dodson–Standing 型图版，纵轴 Cw、参数为温度）：(p=14MPa, T=80℃) 处读得 Cw⁰ ≈ 4.6×10⁻⁴ MPa⁻¹（≈4.55×10⁻¹⁰ Pa⁻¹，与 IAPWS 纯水物性数据一致）；
② 矿化度校正：溶解盐“撑住”水分子骨架，盐水比纯水更难压缩——查矿化度校正曲线，40000mg/L 对应校正系数 ≈ 0.96（每 10000mg/L 约降 1%）。
1
纯水：Cw⁰(14MPa, 80℃) ≈ 4.55×10⁻⁴ MPa⁻¹。
2
校正：Cw = Cw⁰ × 0.96 ≈ 4.4×10⁻⁴ MPa⁻¹。
答案 Cw ≈ 4.4×10⁻⁴ MPa⁻¹（即 4.4×10⁻¹⁰ Pa⁻¹ ≈ 3.0×10⁻⁶ psi⁻¹）。图版读数允许 ±10% 差异，答案在 4.2～4.7×10⁻⁴ MPa⁻¹ 之间均算正确。
标注要点
  1. 量级对比是考点：Cw~10⁻⁴ MPa⁻¹ << Co~10⁻³ MPa⁻¹（上一题算的原油 1.92×10⁻³）——水的弹性驱动能量远小于油，天然弹性驱里“水顶”贡献有限。
  2. 温度的影响大于压力：纯水压缩系数随温度升高而增大（80℃ 明显大于常温的 ~4.6×10⁻⁴ MPa⁻¹ 基线），随压力增大而略减；矿化度升高使 Cw 减小。三个方向都要记住。
  3. 单位换算易错：1×10⁻⁴ MPa⁻¹ = 6.89×10⁻⁷ psi⁻¹？不——1 MPa⁻¹ = 145.0 psi⁻¹？分清楚：1/MPa 换算到 1/psi 要除以 145（1MPa=145psi，压强单位越大其倒数越小）：4.4×10⁻⁴/145 ≈ 3.0×10⁻⁶ psi⁻¹ ✓。

溶解气油比 Rs（图版法）

图版法 答案：Rs ≈ 67 m³/m³（≈376 scf/STB，图版读数 65～70 均可）
题目 已知某油藏温度 t=79.5℃，产出的油罐原油相对密度 γo=0.89，天然气相对密度 γg=0.7，目前地层饱和压力 15MPa，求目前溶解气油比（用图版法）。
思路 · 方法标注 用Standing 溶解气油比图版（教材附录图版；其数学形式即 Standing 1947 关联式，单位用矿场制）：

Rs = γg · [ p·10(0.0125·API − 0.00091·T) / 18 ]1.2048

p：psia；T：℉；API = 141.5/γo − 131.5；Rs：scf/STB（1 scf/STB = 0.17811 m³/m³）

图版用法：以 API 为横轴、温度作参数曲线族先定“气体溶解能力系数”，再由压力与 γg 读出 Rs——与公式完全等价。
1
单位换算：T = 79.5×1.8+32 = 175.1℉；p = 15MPa = 2175.6 psia；API = 141.5/0.89 − 131.5 = 27.5。
2
算指数项：0.0125×27.5 − 0.00091×175.1 = 0.3436 − 0.1593 = 0.1843 ⇒ 100.1843 = 1.529。
3
代公式：Rs = 0.7×(2175.6×1.529/18)1.2048 = 0.7×(184.8)1.2048 = 0.7×537 = 376 scf/STB。
4
换算：376×0.17811 ≈ 67 m³/m³。
答案 Rs ≈ 67 m³/m³（≈376 scf/STB）。直接查图版读数在 65～70 m³/m³ 之间均算正确。
标注要点
  1. 四个量的单调关系（考概念必背）：压力↑→Rs↑（溶解更多）；API↑（油变轻）→Rs↑；γg↑（气变重、含更多可溶重组分）→Rs↑；温度↑→Rs↓（分子动能大、溶解度降）。
  2. 注意用“油罐油”相对密度：图版与关联式的基准是地面脱气油（stock-tank oil），题给 γo=0.89 正是它；不要误用地层油密度。
  3. 单位陷阱：公式里 p 一定要用 psia、T 用华氏度；最后结果按题目要求的 m³/m³ 报出，换算系数 0.17811（或 ×5.615 反向）要写清。

地层油体积系数 Bo（图版法）

图版法 答案：Bo ≈ 1.27 m³/m³（图版读数 1.26～1.28 均可）
题目 已知某地层温度 t=80.0℃，溶解气油比 Rs=80m³/m³；天然气相对密度 γg=0.8，地面脱气油相对密度 γo=0.78，求地层油体积系数（用图版法）。
思路 · 方法标注 用 Standing 地层油体积系数图版（数学形式为 Standing Bo 关联式，矿场制单位）：

Bo = 0.9759 + 1.2×10⁻⁴ · F1.2F = Rs·(γg/γo)0.5 + 1.25·T

Rs：scf/STB；T：℉（F 是把 Rs、γg/γo、温度三个影响项合成一个“膨胀因子”）

图版用法：由 Rs 与 (γg/γo)0.5 定中间量，加温度项后沿图版曲线读 Bo。
1
单位换算：T = 80×1.8+32 = 176℉；Rs = 80×5.615 = 449.2 scf/STB；API = 141.5/0.78 − 131.5 = 49.9（轻质油）。
2
算 F：F = 449.2×(0.8/0.78)0.5 + 1.25×176 = 449.2×1.0127 + 220 = 454.9 + 220 = 674.9。
3
代公式：F1.2 = 674.91.2 ≈ 2484；Bo = 0.9759 + 1.2×10⁻⁴×2484 = 0.9759 + 0.298 = 1.274。
答案 Bo ≈ 1.27 m³/m³。查图版读数在 1.26～1.28 之间均算正确。
标注要点
  1. 物理意义自查：Rs=80 m³/m³ 属中低溶解气油比，1 m³ 地面油溶进 80 m³ 标准气后地下占 1.27 m³——气把油“撑胖”了 27%，合理（Bo 恒 >1）。
  2. Bo 的单调关系：Rs↑、API↑（油轻）、T↑、γg↓（轻气分子小、同质量占体积大）⇒ Bo↑。与第 7 题 Rs 的关系对照记忆：γg 对 Rs 是正贡献、对 Bo（在 Rs 固定时）是负贡献——因为公式里 γg 出现在 F 的减效位置 (γg/γo)0.5 只影响 Rs 项的权重。
  3. 两题是一对逆问题：第 7 题由 p、T、γ 求 Rs；本题由 Rs、T、γ 求 Bo——PVT 图版法三件套还有第三个：由 Rs、γo、γg、T 求地层油密度/泡点密度，考试常轮换出题。
  4. 单位陷阱：Rs 进公式前必须 ×5.615 换成 scf/STB；温度必须换华氏度。换算错了 Bo 能差出 0.1 量级。
