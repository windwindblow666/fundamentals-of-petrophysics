组成换算：求质量分数和体积分数

基础知识 答案：w = 0.711 / 0.075 / 0.081 / 0.074 / 0.059；体积分数 = 摩尔分数
题目 已知天然气组成 CH₄ 0.870、C₂H₆ 0.049、C₃H₈ 0.036、i-C₄H₁₀ 0.025、n-C₄H₁₀ 0.020（摩尔分数），求各组分的质量分数和体积分数。
思路 · 方法标注 ① 基准法：取 1 mol 混合气作计算基准（取 100 mol 结果相同），把“分数”运算转化为“先算绝对量、再归一化”，最不容易出错。
② 质量换算：mi = yiMi，wi = mi/Σmi。
③ 体积分数：低压下天然气近似理想气体，由阿伏伽德罗定律——同温同压下体积比 = 摩尔数比，故 体积分数 = 摩尔分数。（前提是理想气体；高压下二者不再相等。）
摩尔质量取教材常用近似值：M(CH₄)=16，M(C₂H₆)=30，M(C₃H₈)=44，M(C₄H₁₀)=58 g/mol。
组分摩尔分数 yiMi (g/mol)mi = yiMi (g)质量分数 wi体积分数
CH₄0.8701613.9200.71080.870
C₂H₆0.049301.4700.07510.049
C₃H₈0.036441.5840.08090.036
i-C₄H₁₀0.025581.4500.07400.025
n-C₄H₁₀0.020581.1600.05920.020
合计1.000—19.5841.00001.000

检验：Σw = 0.7108+0.0751+0.0809+0.0740+0.0592 = 1.0000 ✓（归一化自查是必做的一步）

答案 质量分数：w(CH₄)=0.711，w(C₂H₆)=0.075，w(C₃H₈)=0.081，w(i-C₄H₁₀)=0.074，w(n-C₄H₁₀)=0.059。
体积分数 = 摩尔分数：0.870 / 0.049 / 0.036 / 0.025 / 0.020。
延伸：混合气视摩尔质量 M = 19.584 g/mol，相对密度 γg = 19.584/28.97 ≈ 0.676（比空气轻，与甲烷为主的干气特征一致）。
标注要点
  1. “体积分数 = 摩尔分数”只在低压（理想气体）成立；高压下需按各组分的 Z 因子修正，不能直接套用。
  2. 基准取 1 mol（或 1 mol 的整倍数）是组成换算类题目的通用技巧。
  3. 算完务必自查：Σy=1、Σw=1；质量分数一定落在 0～1 之间。

含 C₇⁺ 的组成换算

基础知识 答案：w = 0.302 / 0.071 / 0.064 / 0.018 / 0.037 / 0.018 / 0.017 / 0.041 / 0.432
题目 已知各组分的摩尔分数（CH₄ 0.6904、C₂H₆ 0.0864、C₃H₈ 0.0534、i-C₄H₁₀ 0.0115、n-C₄H₁₀ 0.0233、i-C₅H₁₂ 0.0093、n-C₅H₁₂ 0.0085、C₆H₁₄ 0.0173、C₇⁺ 0.0999），求各组分的质量分数和体积分数。C₇⁺ 的相对密度为 0.827，摩尔质量为 158 g/mol。
思路 · 方法标注 与第 6 题完全同法：取 1 mol 基准，mi=yiMi 后归一化。区别在于本题出现拟组分 C₇⁺：它没有单一化学式，题给 M=158 g/mol 直接代入即可（相对密度 0.827 只有一个用途——需要把 C₇⁺ 的质量换算成体积时才用 ρ=0.827 g/cm³，本题求质量/体积分数用不到）。体积分数仍按理想气体处理：体积分数 = 摩尔分数。

延伸：M = 36.560 g/mol，γg = 36.56/28.97 ≈ 1.262——比空气重，是典型的富气（湿气）。

  2. 相对密度 γg>1 ⇒ 气体比空气重；若题目再给温度和压力，可由 γg 进一步求密度 ρg=1.205·γg（标况）等。
  3. C₇⁺ 的“相对密度 0.827”在本题是干扰信息，不要误用它去算摩尔质量（题已直接给出 M=158）。

反向换算：由质量分数求摩尔分数

基础知识 答案：y = 0.948 / 0.0247 / 0.0165 / 0.0104
题目 已知质量分数：CH₄ 0.880、C₂H₆ 0.043、C₃H₈ 0.042、n-C₄H₁₀ 0.035，求各组分的摩尔分数。
思路 · 方法标注 第 6、7 题是“摩尔 → 质量”，本题是反向运算，基准法照样适用：取 100 g 混合气（因为质量分数天然是“百分含量”）， ni = 100wi/Mi，yi = ni/Σni。 注意：除以的是各组分自己的摩尔质量，不是平均摩尔质量。
组分质量分数 wiMi (g/mol)ni = 100wi/Mi (mol)摩尔分数 yi
CH₄0.8801688/16 = 5.5000.9484
C₂H₆0.043304.3/30 = 0.14330.0247
C₃H₈0.042444.2/44 = 0.09550.0165
n-C₄H₁₀0.035583.5/58 = 0.06030.0104
合计1.000—5.79911.0000
答案 摩尔分数：y(CH₄)=0.948，y(C₂H₆)=0.0247，y(C₃H₈)=0.0165，y(n-C₄H₁₀)=0.0104。
延伸：M = 100/5.7991 = 17.24 g/mol，γg = 17.24/28.97 ≈ 0.595——甲烷占 94.8%，典型干气。
标注要点
  1. 与 6、7 题对比：轻组分（甲烷）在摩尔分数中被“放大”（w=0.880 → y=0.948），重组分被“缩小”。M 越小，同样的质量对应越多摩尔数。
  2. 基准取 100 g 而不是 1 g，可免除大量小数运算，考试省时间且不易错。
  3. 平均摩尔质量有两种算法，结果应一致：ΣyiMi = 1/Σ(wi/Mi) = 17.24 g/mol，可用来互检。

理想气体的等容过程（查理定律）

温标陷阱 答案：p₂ ≈ 602 kPa
题目 理想气体在 40 ℃ 时产生 690 kPa 的压力。当体积保持不变、温度降为 0 ℃ 时，产生多大压力？
思路 · 方法标注 体积、物质的量都不变（只是降温）⇒ 等容过程，由理想气体状态方程直接得到查理定律： p₁/T₁ = p₂/T₂，即 p₂ = p₁·T₂/T₁。
⚠️ T 必须用热力学温度（K）：把℃换成 K 再代入，这是本题唯一陷阱。
1
换温标
T₁ = 40 + 273.15 = 313.15 K；T₂ = 0 + 273.15 = 273.15 K
2
代入查理定律
p₂ = 690 × 273.15/313.15 = 690 × 0.8723 = 601.9 kPa
（按 T₁=313 K、T₂=273 K 计算得 601.8 kPa，差别可忽略）
答案 温度降到 0 ℃ 时压力为 p₂ ≈ 602 kPa。
标注要点
  1. 必须用绝对温标：若错用摄氏温标得 690×0/40 = 0，完全错误。判断技巧——理想气体公式里的 T 一律是 K。
  2. 压力不高（≈0.7 MPa）时天然气 Z≈0.99，理想气体近似误差 <1%，本题按理想处理完全合理；严格式为 p₂ = p₁·(Z₂T₂)/(Z₁T₁)。

Z 因子计算：Kay 规则 + Wichert–Aziz 酸气校正

五步法 答案：Z ≈ 1.01（ppr = 7.68，tpr = 1.78）
题目 求下列气体在 37.5 MPa、125 ℃ 下的 Z 因子：H₂S 0.100、CO₂ 0.050、CH₄ 0.724、C₂H₆ 0.062、C₃H₈ 0.037、n-C₄H₁₀ 0.027（摩尔分数）。
思路 · 方法标注（天然气 Z 因子五步法） ① 列出组成 → ② Kay 混合规则求假临界参数 → ③ 含 H₂S/CO₂，做 Wichert–Aziz 校正 → ④ 算视对比参数 ppr、Tpr → ⑤ 查 Standing–Katz 图版得 Z。
判断依据：酸气总量 yH₂S+yCO₂ = 15% > 5%，不校正会产生明显误差，必须校正。

① Kay 混合规则

得假临界参数：Tpc = 234.62 K，Ppc = 5.161 MPa

② Wichert–Aziz 校正（酸气校正）

1
定义：A = yH₂S + yCO₂ = 0.100+0.050 = 0.150，B = yH₂S = 0.100（A 是酸气总量，B 只有 H₂S）
2
校正因子：ε = 120(A0.9−A1.6) + 15(B0.5−B4)
　= 120×(0.1813−0.0481) + 15×(0.3162−0.0001) = 20.73 °R = 20.73×5/9 = 11.52 K
3
校正后的假临界参数：
Tpc′ = Tpc − ε = 234.62 − 11.52 = 223.10 K
Ppc′ = Ppc·Tpc′ / [Tpc + B(1−B)ε] = 5.161×223.10 / (234.62+0.10×0.90×11.52) = 1151.4/235.66 = 4.886 MPa

③ 视对比参数 → 查图版

1
ppr = p/Ppc′ = 37.5/4.886 = 7.68
2
Tpr = T/Tpc′ = (125+273.15)/223.10 = 1.78
3
查 Standing–Katz 图版（本页用与图版等价的 Hall–Yarborough 关联式给出精确值，图版手工读数吻合）：Z ≈ 1.012 ≈ 1.01
答案 37.5 MPa、125 ℃ 下 Z ≈ 1.01（查图版读数约 1.0～1.03 均可接受）。
对照（供理解校正作用）：不做 W-A 校正时 ppr=7.27、Tpr=1.70 → Z≈0.98，校正使 Z 提高约 3%。
标注要点
  1. 先判断要不要校正：酸气（H₂S+CO₂）含量大时必须做 W-A 校正，教材常用判据为总酸气量 >5%。
  2. A、B 的定义别记反：A = H₂S+CO₂（酸气总量），B = 仅 H₂S 含量。
  3. ε 公式的单位是 °R，换算成 K 要乘 5/9；Ppc′ 的分母要用“未校正的 Tpc”加上修正项。
  4. 中高压气藏（本题 37.5 MPa）通常 Z>1，若算出 Z<0.5 之类应立刻怀疑算错。

等温压缩实验：由 p–V 数据求 Z 并作图

实验数据处理 答案：Z 由 0.914 降到 0.645（13.8 MPa）再回升至 0.949
题目 一气缸内气体初始压力 0.1 MPa、体积 75000 cm³，恒温 93 ℃。注入汞压缩，记录 8 组压力（MPa）与体积（cm³）： p：2.8，5.5，8.3，13.8，17.3，20.7，27.6，34.5；V：2448，1080，648.6，350.6，295.9，266.4，234.6，206.2。 求各压力下的理想体积，并计算 Z 因子，绘 Z–p 图。
思路 · 方法标注 ① 先标定物质的量：初始态只有 0.1 MPa，压力极低，可视作理想气体（Z≈1），由它求 n；之后全程恒温、恒 n。
② 理想体积：V理 = nRT/p；③ 偏差因子即“实际/理想体积比”：Z = pV/(nRT) = V实/V理。
④ 关键恒等式：nRT = p₀V₀ ⇒ Z = pV/(p₀V₀)，分母是个常数 7500 J。
1
求 n（T = 93+273.15 = 366.15 K，V₀ = 0.075 m³）
n = p₀V₀/(RT) = 0.1×10⁶×0.075 / (8.314×366.15) = 2.4636 mol，故 nRT = p₀V₀ = 7500 J
